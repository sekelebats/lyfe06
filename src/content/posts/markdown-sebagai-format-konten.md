Markdown adalah salah satu format favorit saya untuk menulis konten website.

Format ini sederhana, mudah dibaca, dan tidak membutuhkan aplikasi khusus untuk memahami isinya.

## Mengapa Markdown?

Berbeda dengan dokumen yang menyimpan banyak informasi format, Markdown tetap berupa teks biasa.

Contoh heading:

```markdown
# Heading 1
## Heading 2
### Heading 3
```

Contoh formatting:

- **Bold** untuk penekanan.
- *Italic* untuk istilah atau penekanan ringan.
- `inline code` untuk kode pendek.
- [Link](https://example.com) untuk referensi.

## Markdown dan Git

Kombinasi Markdown dan Git memberikan workflow yang menarik.

1. Tulis konten dalam file `.md`.
2. Simpan perubahan menggunakan Git.
3. Jalankan proses build.
4. Publikasikan hasilnya ke hosting.

Setiap perubahan dapat dilacak melalui version control.

## Markdown bukan sekadar format

Markdown membantu memisahkan konten dari tampilan.

Konten dapat tetap digunakan meskipun desain website berubah.

> Write once, use anywhere.

## Kesimpulan

Saya menyukai Markdown karena sederhana, portabel, dan tidak membuat proses menulis menjadi rumit.
