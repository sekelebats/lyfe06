# Minimal Markdown Kit

Minimal Markdown Kit adalah kumpulan template untuk membantu mengelola tulisan, catatan, dan dokumentasi menggunakan Markdown.

## Apa yang didapatkan?

- Template artikel blog.
- Template catatan harian.
- Template dokumentasi proyek.
- Template README.
- Panduan struktur Markdown.

## Keunggulan

### Sederhana

Tidak membutuhkan aplikasi khusus untuk membaca file.

### Portabel

File dapat dibuka menggunakan text editor apa pun yang mendukung teks biasa.

### Mudah dikembangkan

Struktur template dapat disesuaikan dengan kebutuhan proyek.

## Format

- Markdown (`.md`)
- Dokumentasi penggunaan (`.md`)
- File contoh
